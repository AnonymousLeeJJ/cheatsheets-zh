# 正则表达式速查表

## 字符类

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `.` | 任意字符（除换行） | `a.c` 匹配 abc、a1c |
| `\d` `\D` | 数字 / 非数字 | `\d{3}` 匹配 123 |
| `\w` `\W` | 单词字符（字母数字下划线）/ 非 | |
| `\s` `\S` | 空白 / 非空白 | |
| `[abc]` | a/b/c 之一 | |
| `[^abc]` | 非 a/b/c | |
| `[a-z]` `[0-9]` | 范围 | |

## 量词

| 语法 | 说明 |
| --- | --- |
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `?` | 0 次或 1 次（也用于非贪婪） |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |
| `*?` `+?` | 非贪婪模式（能少则少） |

## 位置

| 语法 | 说明 |
| --- | --- |
| `^` | 行首 |
| `$` | 行尾 |
| `\b` | 单词边界（`\bcat\b` 不匹配 category） |

## 分组与逻辑

| 语法 | 说明 |
| --- | --- |
| `(abc)` | 捕获分组（可用 `\1` 引用） |
| `(?:abc)` | 非捕获分组 |
| `a|b` | 或 |
| `(?=...)` | 正向先行断言 |
| `(?!...)` | 反向先行断言 |
| `(?<=...)` | 正向后行断言（部分引擎支持） |

## 常用实战模板

```regex
手机号（中国）        ^1[3-9]\d{9}$
邮箱（简化版）        ^[\w.+-]+@[\w-]+\.[\w.]+$
URL（简化版）         ^https?://[\w.-]+(:\d+)?(/\S*)?$
IPv4                 ^(\d{1,3}\.){3}\d{1,3}$
日期 YYYY-MM-DD      ^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$
强密码（8位+含大小写数字）  ^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$
提取引号内容          "([^"]*)"
匹配 HTML 标签        <(\w+)[^>]*>.*?</\1>
中文字符             [一-龥]
行尾空格             \s+$
```

## 经典案例拆解

**匹配 18 位身份证号（简化）：**
```
^\d{17}[\dXx]$
```

**提取 Markdown 图片地址 `![alt](url)`：**
```
!\[([^\]]*)\]\(([^)]+)\)
```

**千分位数字 1,234,567：**
```
^\d{1,3}(,\d{3})*$
```

## 常见坑

1. **贪婪陷阱**：`<.+>` 匹配整行 HTML，应该用 `<[^>]+>` 或 `<.+?>`
2. **`.` 不跨行**：想跨行匹配用 `[\s\S]` 或开 DOTALL 模式
3. **转义层级**：字符串里写正则时 `\d` 要写成 `\\d`
4. **|^ 空匹配**：`(a|)` 能匹配空串，分支顺序有影响
