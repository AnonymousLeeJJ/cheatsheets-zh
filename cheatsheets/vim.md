# Vim 速查表

## 模式

| 按键 | 说明 |
| --- | --- |
| `i` / `a` / `o` | 光标前 / 后 / 下一行 进入插入模式 |
| `Esc` | 回到普通模式 |
| `v` / `V` / `Ctrl+v` | 字符 / 行 / 块 可视模式 |
| `:` | 命令模式 |

## 移动

| 按键 | 说明 |
| --- | --- |
| `h j k l` | 左 下 上 右 |
| `w` / `b` | 下一个 / 上一个单词 |
| `0` / `^` / `$` | 行首 / 第一个非空字符 / 行尾 |
| `gg` / `G` | 文件头 / 文件尾 |
| `:{行号}` | 跳到指定行 |
| `%` | 匹配括号间跳转 |
| `Ctrl+d` / `Ctrl+u` | 向下 / 向上半屏 |
| `*` / `#` | 向下 / 向上搜索光标下单词 |

## 编辑

| 按键 | 说明 |
| --- | --- |
| `x` | 删除字符 |
| `dd` | 删除（剪切）整行 |
| `yy` | 复制整行 |
| `p` / `P` | 粘贴到后 / 前 |
| `u` / `Ctrl+r` | 撤销 / 重做 |
| `cw` | 修改一个单词 |
| `ci"` | 修改引号内内容（同理 `ci(``ci{`） |
| `r<字符>` | 替换单个字符 |
| `J` | 合并下一行到当前行 |
| `>>` / `<<` | 缩进 / 反缩进 |
| `.` | 重复上一次修改（神技） |

## 组合公式：操作 + 范围

`d`（删）`y`（复制）`c`（改）+ 移动范围：

| 命令 | 效果 |
| --- | --- |
| `dw` | 删到单词尾 |
| `d$` | 删到行尾 |
| `dgg` | 删到文件头 |
| `y3j` | 复制向下 3 行 |
| `ct)` | 改到 ) 之前 |

## 搜索替换

| 命令 | 说明 |
| --- | --- |
| `/关键字` 然后 `n`/`N` | 向下搜索，下一个/上一个 |
| `:%s/旧/新/g` | 全文替换 |
| `:%s/旧/新/gc` | 全文替换并逐个确认 |
| `:10,20s/旧/新/g` | 只替换 10-20 行 |

## 多文件与分屏

| 命令 | 说明 |
| --- | --- |
| `:sp` / `:vsp` | 水平 / 垂直分屏 |
| `Ctrl+w 方向键` | 切换窗口 |
| `:bn` / `:bp` | 下一个 / 上一个 buffer |
| `:e 文件` | 打开文件 |

## 保存退出（经典难题）

| 命令 | 说明 |
| --- | --- |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` / `ZZ` | 保存并退出 |
| `:q!` / `ZQ` | 不保存强制退出 |
| `:w !sudo tee %` | 忘记 sudo 打开时的保存大法 |
