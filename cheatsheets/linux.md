# Linux 速查表

## 文件与目录

| 命令 | 说明 |
| --- | --- |
| `ls -lah` | 详细列表（含隐藏文件、人类可读大小） |
| `cd -` | 回到上一个目录 |
| `pwd` | 当前路径 |
| `mkdir -p a/b/c` | 递归创建目录 |
| `cp -r 源 目标` | 递归复制 |
| `mv 源 目标` | 移动/重命名 |
| `rm -rf <目录>` | 强制删除（⚠️ 不可恢复，慎用） |
| `ln -s 目标 链接名` | 创建软链接 |
| `touch <文件>` | 创建空文件/更新时间戳 |

## 查找文件

| 命令 | 说明 |
| --- | --- |
| `find . -name "*.log"` | 按文件名查找 |
| `find . -type f -size +100M` | 找大于 100M 的文件 |
| `find . -mtime -7` | 7 天内修改过的文件 |
| `which <命令>` | 命令的安装路径 |
| `grep -rn "关键字" .` | 递归搜索文件内容 |
| `grep -rl "关键字" .` | 只列出匹配的文件名 |

## 查看文件

| 命令 | 说明 |
| --- | --- |
| `cat` / `less` | 全文查看 / 分页查看 |
| `head -n 50 <文件>` | 前 50 行 |
| `tail -n 50 <文件>` | 后 50 行 |
| `tail -f <文件>` | 实时跟踪日志 |
| `wc -l <文件>` | 统计行数 |
| `du -sh <目录>` | 目录总大小 |
| `df -h` | 磁盘剩余空间 |

## 权限

| 命令 | 说明 |
| --- | --- |
| `chmod +x <脚本>` | 加执行权限 |
| `chmod 755 <文件>` | rwxr-xr-x |
| `chmod -R 644 <目录>` | 递归设置 |
| `chown 用户:组 <文件>` | 改所有者 |
| `sudo !!` | 用 sudo 重跑上一条命令 |

## 进程

| 命令 | 说明 |
| --- | --- |
| `ps aux | grep <关键字>` | 查找进程 |
| `top` / `htop` | 实时进程监控 |
| `kill <PID>` | 结束进程 |
| `kill -9 <PID>` | 强制结束（最后手段） |
| `nohup <命令> &` | 后台运行，退出终端不中断 |
| `jobs` / `fg %1` / `bg %1` | 查看 / 前台 / 后台任务 |

## 网络

| 命令 | 说明 |
| --- | --- |
| `curl -I <url>` | 只看响应头 |
| `curl -o 文件 <url>` | 下载文件 |
| `ping <主机>` | 测试连通性 |
| `ss -tlnp` | 查看监听端口及进程 |
| `scp 文件 用户@主机:路径` | 跨机器拷贝 |
| `ssh 用户@主机` | 远程登录 |

## 压缩解压

| 命令 | 说明 |
| --- | --- |
| `tar -czvf a.tar.gz 目录` | 打包压缩 |
| `tar -xzvf a.tar.gz` | 解压 |
| `zip -r a.zip 目录` / `unzip a.zip` | zip 压缩 / 解压 |

## 实用组合技

```bash
# 找出占用 8080 端口的进程并杀掉
kill $(ss -tlnp | grep 8080 | grep -oP 'pid=\K[0-9]+')

# 统计当前目录各子目录大小并排序
du -sh */ | sort -rh

# 批量把 .jpeg 重命名为 .jpg
for f in *.jpeg; do mv "$f" "${f%.jpeg}.jpg"; done
```
