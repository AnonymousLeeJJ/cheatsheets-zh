# VS Code 快捷键速查表（Windows / Mac）

> Mac 用户把 `Ctrl` 换成 `Cmd`，`Alt` 换成 `Option`

## 高频必备

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 快速打开文件（神器） |
| `Ctrl+Shift+P` | 命令面板（万能入口） |
| `Ctrl+`` ` | 打开/关闭终端 |
| `Ctrl+B` | 开关侧边栏 |
| `Ctrl+Shift+F` | 全局搜索 |
| `Ctrl+H` | 当前文件替换 |
| `Ctrl+/` | 注释/取消注释 |
| `Ctrl+S` / `Ctrl+K S` | 保存 / 全部保存 |

## 光标与选择（效率核心）

| 快捷键 | 功能 |
| --- | --- |
| `Alt+点击` | 添加多个光标 |
| `Ctrl+D` | 选中当前单词，再按选中下一个相同词（批量改名神器） |
| `Ctrl+Shift+L` | 选中所有相同词 |
| `Shift+Alt+↓` | 向下复制一行 |
| `Alt+↑/↓` | 整行上移/下移 |
| `Ctrl+Shift+K` | 删除整行 |
| `Ctrl+L` | 选中整行 |
| `Ctrl+Enter` | 下方插入新行 |
| `Ctrl+Shift+Enter` | 上方插入新行 |

## 代码导航

| 快捷键 | 功能 |
| --- | --- |
| `F12` | 跳转到定义 |
| `Alt+F12` | 速览定义（不跳转） |
| `Shift+F12` | 查看所有引用 |
| `F2` | 重命名符号（全项目安全改名） |
| `Ctrl+T` | 按符号搜索（函数/类） |
| `Ctrl+G` | 跳到指定行 |
| `Alt+←/→` | 前进/后退（浏览历史） |
| `Ctrl+Tab` | 在最近文件间切换 |

## 编辑增强

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Space` | 触发补全 |
| `Ctrl+.` | 快速修复（自动 import 等） |
| `Shift+Alt+F` | 格式化文档 |
| `Ctrl+K Ctrl+X` | 删除行尾空格 |
| `Ctrl+]` / `Ctrl+[` | 缩进/反缩进 |
| `Ctrl+Shift+\` | 跳到匹配括号 |
| `Ctrl+K Ctrl+0` | 折叠全部 |
| `Ctrl+K Ctrl+J` | 展开全部 |

## 分屏与窗口

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+\` | 左右分屏 |
| `Ctrl+1/2/3` | 聚焦第 N 个编辑组 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Shift+T` | 重开刚关闭的标签 |
| `Ctrl+K Z` | 禅模式（专注写码） |

## 值得装的通用插件

- **Error Lens** — 行内直接显示报错，不用 hovering
- **GitLens** — 每行代码显示谁改的、什么时候
- **Path Intellisense** — 路径自动补全
- **Auto Rename Tag** — 改开标签自动改闭标签（前端）
- **Todo Tree** — 汇总所有 TODO 注释
