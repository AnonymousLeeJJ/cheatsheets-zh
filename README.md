## 🤔 为什么做这个库？

网上的速查表要么是全英文、要么是图片（没法搜索复制）、要么又长又全根本不适合「查」。

本库的原则：**只放高频内容，表格化呈现，打开 10 秒内找到你要的那条命令。**
